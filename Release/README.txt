========================================================================
             SMART FACTORY: OPC UA SERVER & MES SYSTEM (RELEASE)
========================================================================

Данная сборка содержит полностью готовый к работе комплекс:
 1. Launcher.exe   - Единый файл запуска всей системы
 2. server.jar     - Backend Spring Boot, встроенный веб-интерфейс React и OPC UA Сервер
 3. simulator.exe  - 2D симулятор производственных линий (меднение, травление и др.)

БЫСТРЫЙ СТАРТ:
1. Убедитесь, что на компьютере установлена Java 17+ (https://adoptium.net/).
2. Запустите "Launcher.exe".
3. Launcher автоматически:
   - Запустит сервер
   - Откроет браузер на http://localhost:8080 (SCADA/MES интерфейс)
   - Запустит 2D симулятор в отдельном окне
4. Для подключения R-PRO или любого другого OPC UA клиента используйте адрес:
   opc.tcp://<IP-адрес-компьютера>:4840/milo

ОСТАНОВКА:
Нажмите клавишу 'Q' в окне Launcher.exe или просто закройте окно консоли. Все дочерние процессы завершатся автоматически.
